# IME

C#（Windows Forms）で制作した、文字入力パッドです。

スマートフォンでの操作を想定して設計していますが、PC上でしか使用できません。

## 使用技術

- C#
- Windows Forms
- JSON

## 基本機能

5×4の20個のボタンを使用し、短押し・長押しと、中央・上下左右への操作を組み合わせたフリック入力を実装しています。

入力中の文字列と確定済みの文章を分けて管理し、文字列の確定、候補の切り替え、カーソル移動、削除、改行などの文章編集にも対応しています。

「ぁ゛」のような複数文字の組み合わせや、任意の文字列を1回の操作で出力できるよう、文字ではなく文字列単位で入力内容を管理しています。

## EditMode

既存のIMEでは各ボタン操作への文字の割り当てがアプリによって固定化されている点を不便に感じ、割り当てをカスタマイズできるEditModeを実装しました。

各ボタン操作の内容はButtonDataとしてJSONで管理しており、通常の文字入力と同じ操作で編集・保存できます。

入力内容には改行を含む文字列も登録でき、文章やアスキーアートなどの保存・出力にも利用できます。

## Palette

日本語・英語以外の言語への対応や、保存したい文章やアスキーアートなど、様々な文字列を利用できるよう、各ボタン操作への割り当てをまとめたJSONファイルをPaletteとして管理しています。

各Paletteは他のPaletteへの参照を複数保持し、UI上でPaletteからPaletteへ移動を繰り返せるため、Paletteの数に上限を必要としない構造になっています。

## CryMode

スマートフォンでは、キーボードのような連打入力を行いづらい点に不便を感じ、CryModeを実装しました。

出力候補となる文字列を画面上に配置し、画面上をなぞることで、通過した文字列を連続して出力できます。

配置・出力は文字列単位で行い、複数の文字列を配置することもできます。

## PaintMode

気軽に絵や図を描くための導線や機能がIME上に備わっていれば、SNSやチャットでのコミュニケーション方法に変化があるかもしれないと考えました。

透過背景のままPNGとして保存し、スタンプのように利用することを想定する一方、図を描く場合などには背景色を設定できるよう、描画レイヤーとは別に背景を管理しています。

その場で簡易的に描くことを目的としているため、一般的な複数レイヤーの管理は採用せず、描画用と背景用の2層のみとしました。

その他の機能として、ペン・消しゴム・塗りつぶし・線幅変更・色選択などに対応しています。

描画内容や設定を保存・復元でき、以前の描画に続きを書き足すこともできます。

## 漢字変換

発表間際に少し時間が余り、当初は要件外としていた漢字変換を、ランダム漢字変換という仕様で実装しています。

常用漢字データをもとに作成した辞書を参照し、同じ読みの候補が複数存在する場合はランダムな漢字に変換する方式としました。

## 制作過程

開発初期には、20個のボタンを動的に生成し、入力内容や実行する処理をJSONから読み込む仕組みを実装しました。

その後、候補切り替え、カーソル移動、削除などの機能を追加しました。機能の増加に伴って文字列の状態管理が複雑になったため、入力中・確定済みの文字列管理などについて、データ構造の変更やリファクタリングを行いました。

その構造をもとにCryMode、EditMode、PaintModeなどを追加し、開発終盤にはスクロール処理や漢字変換を実装しました。
